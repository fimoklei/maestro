- **2026-07-02 · tooling/rtk-masks-gh-checks** (archived 2026-07-22: 20 days with no reconfirmation, and RTK-masking claims have proven version-dependent — see the `RTK-masks-output` entry below) — `gh pr checks <n> --watch --interval 15` through the RTK hook did **not** block: it returned one canned snapshot (`Passed: 2 / Failed: 0 / Pending: 7`) and exited 0 while checks were still pending — a merge gate would fire on incomplete CI. → In workflow-ship, don't trust `gh pr checks --watch` under RTK. - **2026-06-21 · web/tailwind-theme-tokens** (archived 2026-07-22: 31 days with no reconfirmation) — Tailwind v4 `@theme inline { --color-x: var(--raw) }` makes utilities compile to `var(--raw)` directly, so a `[data-theme="light"]` override of `--raw` re-skins everything (the shadcn pattern). Theme-independent constants (radii/type/spacing) go in a plain `@theme {}` with literal values; do **not** self-reference (`--radius-tag: var(--radius-tag)` is circular). Verify utility generation with `pnpm dlx @tailwindcss/cli@4` + `@source inline("…")` (the `--content` flag is v3-only and silently ignored). → See `packages/web/src/styles/{tokens,theme}.css` for the split.

- **2026-05-30 · tooling/RTK-masks-output** (archived 2026-06-13) — Was Active: claimed RTK replaced Biome's stdout with a canned `Lint: No issues found` line and corrupted the exit code, so `pnpm exec biome check .` looked green while it actually failed (blamed for two broken commits). **Not reproducible at rtk 0.42.0 on 2026-06-13.** Differential in maestro: `pnpm lint` (= `biome check .`) through the live RTK hook returns honest output — an injected real error gave exit 1 with full detail; `pnpm exec biome check .` showed real output, not the canned line.
